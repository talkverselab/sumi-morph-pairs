# sumi-morph-pairs

Traditional East Asian ink wash (sumi-e) morph pairs.
A-cut is the object. B-cut is the matching Chinese character, same position and visual weight.

## 火 (huo / fire)

| File | Cut |
|---|---|
| `huo/A_campfire.jpg` | A — stacked firewood and flames |
| `huo/B_character.jpg` | B — character 火, dry-brush, 4 strokes |

Pair only matching variation numbers. Keep 1:1 framing. Verify 火 is four strokes (two shoulder ticks + 人-like pair), not 木 / 人 / 大.
